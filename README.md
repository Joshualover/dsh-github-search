# dsh-github-search

在 DeepSeek Harness 里直接搜 GitHub 项目，不用打开 github.com。

左栏会多一个「GitHub 项目搜索」入口；点开就是一页搜索：输入关键词，结果以列表形式列出仓库的星标数、fork 数、语言、许可证、最近更新时间和简介。点开任意一条可以读 README、看语言构成、在浏览器里打开、复制 clone 命令或仓库地址。

## 怎么用

1. 左栏点 GitHub 搜索图标（放大镜＋号）。
2. 输入关键词，回车或点「搜索」。
3. 顶部一排按钮切换排序：最佳匹配 / 星标最多 / fork 最多 / 最近更新。
4. 右侧两个下拉框按语言、按最低星标数筛选；「只搜名字」把关键词限制在仓库名里。
5. 点任意一条展开 README 与语言构成。
6. 点搜索按钮右边的「清空」，一键清空关键词、结果、详情缓存和筛选条件，回到初始状态；正在进行中的搜索也会被作废，不会清空后又自己冒出结果。
7. 输入框下方是**最近搜索**标签行：自动记录每次查询，最多存 10 条、显示 8 条；点任意标签即填入输入框并重新搜索，右侧「清空历史」把整行擦掉。
8. 展开任意项目后，README 上方有**「翻译成中文」**按钮：一键把英文 README 译成中文并替换显示，再点「看原文」切回。翻译保留 Markdown 结构（标题、列表、表格、代码块、链接），代码、命令、标识符和专有名词不翻译。README 超过 8000 字符时只译前 8000 字符，并明确提示。

面板右上角显示当前剩余配额。

## 配额与 token

GitHub 搜索接口对未认证请求的限制很紧：**每个 IP 每分钟只有 10 次**。插件按以下顺序找 token，找到就用，把配额提到每分钟 30 次、每小时 5000 次：

1. `cordis.patch.yml` 里本行配置的 `config.token`
2. 本机 `gh` CLI 的登录凭据（`~/.config/gh/hosts.yml`）；把 `config.useGhToken` 设成 `false` 可以跳过
3. 环境变量 `GITHUB_TOKEN` 或 `GH_TOKEN`

检测到本机 `gh` 已登录时会自动用上，通常不用额外配置。要手动指定：

```yaml
- insert:
    - id: dsh-github-search
      name: 'dsh-github-search'
      config:
        token: 'github_pat_...'
```

## 给 agent 的工具

插件同时注册两个只读工具，界面和工具走同一套逻辑：

- `github_search` —— 按关键词、语言、topic、作者、最低星标、许可证搜仓库，可排序分页。
- `github_repo` —— 读单个仓库的详情、语言构成与 README，接受 `owner/repo` 或 github.com 链接。
- `github_translate_readme` —— 把某个仓库的 README（或已取得的 README 文本）译成中文，保留 Markdown 结构。

## 数据与隐私

- 请求只包含你输入的搜索词与筛选条件，经本机 Host 转发到 `api.github.com`。
- 全部操作只读，不改动任何仓库。
- 搜索历史保存在浏览器的 `localStorage`（键名 `dsh-github-search:history`），只存在你自己的浏览器里、不会上传；点「清空历史」即删除。
- **翻译会把 README 正文发送给模型。** 走的是你当前已在 DSH 里配置好的模型路由，用的是你自己的凭据；如果 DSH 挂载了内置翻译服务（`translator`），优先用它。README 内容是公开文档，但请知悉这一步确实把文本发给了模型服务商。
- 关掉插件会移除面板、左栏入口和两个工具。

## 结构

| 文件 | 作用 |
|---|---|
| `index.js` | Host 半片：`/dsh-github-search/*` 路由、token 解析、两个 agent 工具 |
| `lib/github.js` | 检索核心：搜索语法拼装、API 调用、错误与限流、仓库瘦身 |
| `client.js` | 浏览器半片：左栏入口 + 搜索面板 |
| `locale/*.json` | 插件市场里显示的标题、说明 |
| `docs/` | 详情页预览图与文档 |

## 已知限制

- GitHub 搜索最多能翻到前 1000 条结果，因此 `page` 上限是 10（每页最多 50）。
- 只做仓库搜索，不做代码搜索、issue 搜索、star 列表。
- README 只取默认分支的，超过 2 万字符会截断。
- 翻译一次只处理前 8000 字符；更长的 README 会截断并提示。
- 翻译不做缓存，每次展开都是重新请求（除非你重新翻译同一项）。
